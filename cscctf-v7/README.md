# CSCCTF v7

The seventh edition of the CTF run by the PSUT Cyber Security Club (CSCP-SUT), held in January 2026 with around 150 players. Challenges were aimed at experienced players.

## My challenges

| Challenge | Category | Difficulty | Techniques |
| :-- | :-- | :-- | :-- |
| [Crypto Heist](forensics/crypto-heist/) | Forensics | Hard | Windows memory forensics with Volatility 3, UTF-16 strings, file cache recovery |
| [Lost Password](forensics/lost-password/) | Forensics | Hard | USB HID mouse and keyboard decoding, 16-bit mouse reports |
| [The Curious Case of DEADBEEF](forensics/the-curious-case-of-deadbeef/) | Forensics | Hard | TLS decryption with key logs, ELF reversing, PBKDF2/AES, OSINT on Git history |

Only challenges I authored are included.
