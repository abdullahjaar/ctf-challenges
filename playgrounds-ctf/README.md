# Playgrounds CTF

A 24-hour jeopardy CTF for beginner players at Princess Sumaya University for Technology (PSUT), held in late 2025 with around 100 participants. This was my first event as a challenge author.

The challenges were aimed at players new to CTFs, so each one teaches one core technique and the standard tool for it.

## My challenges

|Challenge|Category|Techniques|
|-|-|-|
|[Permutational Hell](forensics/permutational-hell/)|Forensics|TCP stream reassembly, sequence number analysis|
|[Shadow Operator](forensics/shadow-operator/)|Forensics|Windows minidump, UTF-16 strings, encoded PowerShell|
|[Inbox Zero](forensics/inbox-zero/)|Forensics|Email header analysis, phishing triage|
|[Internal Affairs](osint/internal-affairs/)|OSINT|Username pivoting across platforms|
|[Silent Document](steg/silent-document/)|Steganography|Hidden PDF text, embedded files|
|[Pixel Perfect](steg/pixel-perfect/)|Steganography|LSB extraction|
|[S0F0](steg/s0f0/)|Steganography|JPEG SOF0 header manipulation|

Only challenges I authored are included.
